# Playtest — Silver City: Unending Evidence

Two bars, scored equally. A dry lesson that nobody finishes fails. A candy puzzle that leaves no claim behind also fails.

| Bar | Question |
| --- | --- |
| **Fun / polish** | Would you open this again tonight? Snappy? Clear? Delightful? |
| **Evidence retention** | After the page folds, can you say the **claim** and **one reason**? |

Do not trade one for the other. Prefer a fix that raises both (satisfying snap → crisp line you rebuild).

## Session (about 8–12 minutes)

1. Fresh install / Reset.
2. Welcome: is **Walk today’s trail** obvious? Tap it.
3. Solve Today’s Trail without peeking if you can.
4. Fold the page. Rebuild claim, then reason. Note whether it felt like a second puzzle or like homework.
5. Confirm streak 1 and the tomorrow teaser.
6. Open the Journal. Note % complete, sealed vs mystery, and whether the new page is face-down.
7. Enter Parable Hollow. Finish one district challenge. Rebuild the line before Continue appears.
8. Replay that challenge with a peek or a miss. Confirm a peek blocks a “clean” rest, and that 3★ is mastery (spaced + said back), not a same-session no-miss badge.
9. Share a morning — read the copied pitch. It should ask what a friend can still say.
10. If a page is due: Journal shows **Due this morning**; Today’s Trail copy is **Time to dust off this one**; solving it can raise 1★ → 2★ (or 3★ with teach-back).

## Self-test (required)

Close the teaching. Do not look back. Speak out loud:

1. The key **claim** from the last walk.
2. **One supporting reason**.
3. A **source** if you can.

Mark pass / thin / gone.

## Review notes
- The lamp is a picture: it only gives light; the neighbor sets it out so others can see (Matthew 5:16 is about people’s good works giving glory to the Father). No sparkles, no lamp power.
- Objects never have power by themselves; no figure other than Jesus carries a JESUS SAID label.
